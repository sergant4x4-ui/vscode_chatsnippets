# ClaudeCode Chat Snippets

Панель крупных иконок у края монитора. Клик по иконке или глобальная горячая клавиша вставляет назначенный текст в окно VS Code (туда, где стоит курсор — обычно поле чата Claude Code). Enter не нажимается.

- Запуск: `dotnet run --project src/ChatSnippets.App`
- Флажок у края экрана — клик выдвигает панель; уходит сама, когда мышь вне панели 1,5 с (pin — не уходить).
- Кнопка «✎ Edit» под «+» включает режим редактирования: клик по иконке открывает окно «Edit icon» (картинка, текст, хоткей, Delete). Режим выключается кнопкой «Done» или когда панель сворачивается.
- Плитка «Aя Layout» вверху исправляет раскладку (ghbdtn ⇄ привет) в чате VS Code: берёт выделенный текст, а если выделения нет — весь текст поля. Хоткей назначается правым кликом по плитке или через шестерёнку.
- При наведении на иконку показывается вставляемый текст.
- Панель двигается за широкую «ручку» с точками в самом верху.
- Правый клик по иконке — Edit / Delete; «+» — новая иконка; иконки перетаскиваются для смены порядка.
- Шестерёнка — сторона экрана и Exit.
- Данные: `%AppData%\ChatSnippets\config.json`, картинки — `%AppData%\ChatSnippets\icons`.
- Вставка работает, только если активно окно VS Code (процесс `Code`). Перед нажатием кликните в поле чата.

- Повторный запуск программы (ярлык) показывает панель, если она потерялась. Журнал: `%AppData%\ChatSnippets\log.txt`.

## Установщик

Готовый `ClaudeCodeChatSnippets-Setup-<версия>.exe` собирается скриптом `installer\build.ps1`
(нужен [Inno Setup 6](https://jrsoftware.org/isinfo.php); путь к `ISCC.exe` можно передать `-Iscc`).
Установщик не требует прав администратора и уже содержит .NET — друзьям ничего докачивать не нужно.
Результат появляется в `installer\Output\` (в git не хранится — выкладывайте на странице Releases).
