# Chat Snippets — дизайн

Дата: 2026-10-03. Стек: C# / WPF / .NET 8 (отдельный проект, не часть EvpatiyBox).

## Цель
Маленькая Windows-утилита для владельца: панель крупных иконок у края монитора. Клик по иконке или глобальная горячая клавиша вставляет назначенный текст в окно VS Code (туда, где стоит текстовый курсор, обычно — поле чата Claude Code). Enter программа не нажимает.

## Источники внешнего вида
- Макет: `F:\_AI Project\EvpatiyBoxApp\.concept\chat-snippets-ui-mockup-vertical-80px.png`
- Спецификация верстки (размеры, цвета, состояния, окно Edit icon): `F:\_AI Project\EvpatiyBoxApp\.concept\CHAT_SNIPPETS_LAYOUT_SPEC.md`
Числа из спецификации верстки имеют приоритет. Ниже — только то, что она не покрывает или что отличается.

## Поведение окна
- Ширина 80 DIP, одна колонка кнопок 64×64, шапка 32 DIP (pin, gear, minus). `Topmost=True`.
- Окно **не забирает фокус** (`WS_EX_NOACTIVATE`): курсор остаётся в поле чата.
- Панель прижата к левому или правому краю рабочей области. Сторону меняют перетаскиванием за шапку (прилипание в пределах 16 DIP).
- **Выезд.** В свёрнутом виде за краем экрана спрятана вся панель, на экране остаётся «флажок» ~16 DIP шириной и 64 DIP высотой с цветом акцента `#4C8DFF`. Клик по флажку выезжает панель (анимация ~180 мс).
- **Сворачивание обратно:** (а) курсор мыши вне панели 1,5 с; (б) повторный клик по флажку; (в) кнопка minus — сразу.
- **Не сворачивается** после вставки текста (ни по клику, ни по хоткею).
- Кнопка pin отключает сворачивание по таймеру (панель остаётся выехавшей).
- Хоткеи работают при свёрнутой панели; флажок на ~1 с вспыхивает зелёным `#35D978` как подтверждение.
- Запоминаются: сторона, вертикальная позиция флажка, монитор, состояние pin.

## Вставка
1. Проверить, что активное окно принадлежит процессу VS Code (`Code.exe`, также `Code - Insiders.exe`). Если нет — текст не вставляется, кнопка мигает красным `#FF5B5B`, буфер обмена не трогается.
2. Сохранить текущее содержимое буфера обмена.
3. Положить в буфер текст сниппета, отправить Ctrl+V через `SendInput`.
4. Подождать ~150 мс и вернуть прежнее содержимое буфера.
5. Показать состояние Success (зелёная рамка, галочка) только после выполнения шагов 3–4.
Занятый буфер обмена: до 3 попыток, затем красное мигание.
Куда внутри VS Code уйдёт текст, решает положение текстового курсора (последний клик пользователя); программа его не определяет и не переключает.

## Иконки и горячие клавиши
- Иконка = пользовательская картинка (PNG/ICO/SVG-растр), копируется в `%AppData%\ChatSnippets\icons`. Отсутствующий файл — заглушка.
- Текст сниппета многострочный. Подпись хоткея выводится из данных под иконкой, без плашки.
- Хоткей глобальный (`RegisterHotKey`), обязателен модификатор (Ctrl/Alt/Shift/Win). Конфликт с другой программой или другой иконкой — сообщение при сохранении, поле остаётся пустым.
- Поле хоткея перехватывает комбинацию, обычный текст не принимает.
- По умолчанию предлагается `Ctrl+Alt+цифра`.

## Редактирование
Левый клик — выполнить. Правый клик по иконке — меню «Изменить / Удалить». Клик по кнопке `+` — новая иконка. Порядок меняется перетаскиванием. Окно `Edit icon` — как в спецификации верстки; Delete требует подтверждения.

## Хранение
`%AppData%\ChatSnippets\config.json`: список иконок (id, путь к картинке, текст, хоткей), сторона/позиция окна, pin. Запись атомарная (временный файл + замена). Битый конфиг переименовывается в `.bad`, запускается с пустым списком.

## Структура кода
- `ChatSnippets.Core` — модель, загрузка/сохранение конфига, нормализация и проверка конфликтов хоткеев, решение «куда сворачивать/где прилипать» (чистая логика позиций).
- `ChatSnippets.App` — WPF: окно, флажок, Edit icon, `HotkeyService` (RegisterHotKey), `PasteService` (проверка процесса, буфер, SendInput).
- `ChatSnippets.Core.Tests` — xUnit: конфиг, хоткеи, позиционирование. Вставку в VS Code проверяет владелец вручную.

## Вне объёма (YAGNI)
Автоматический Enter, переключение фокуса на чат, группы/папки иконок, облачная синхронизация, горизонтальный режим, вставка в другие программы.

## Критерии готовности
- Панель 80 DIP, кнопки 64×64, состояния как в спецификации верстки.
- Клик и хоткей вставляют текст в поле чата VS Code при активном VS Code и не вставляют при другом активном окне.
- Прежний буфер обмена восстанавливается.
- Выезд/сворачивание работают с обеих сторон, на нескольких мониторах и при 100–200% DPI.
- Настройки переживают перезапуск.

## Уточнения при реализации (2026-10-03)
- Док: по окончании перетаскивания панель прилипает к ближайшему краю рабочей области монитора (а не только в пределах 16 DIP), т.к. без дока нет флажка.
- Окно с `AllowsTransparency=True` и скруглённой рамкой (на Windows 10 `WindowChrome` не скругляет углы).
- Шестерёнка открывает меню: «Left side» / «Right side» и «Exit». Других настроек нет (значка в трее нет, выйти можно только так).
- Позиционирование — в физических пикселях (`SetWindowPos`), масштаб берётся из DPI окна.
- В свёрнутом виде окно панели скрыто (`SW_HIDE`), виден только окно-флажок.
- Буфер обмена восстанавливается только если там был текст; картинка/файлы в буфере при вставке теряются.
